### Jenkins Configuration
- Jenkins was installed and configured on Windows.
- A Pipeline job named DevOps-Lab-1 was created.
- The job was connected to the public GitHub repository.
- Branch configured: main.
- Pipeline script: Jenkinsfile.
- Poll SCM was configured with the schedule H/2 * * * *.

### Jenkins Pipeline Stages
1. Checkout: Retrieves source code from GitHub.
2. Build: Installs Python dependencies.
3. Test: Runs automated Pytest tests.
4. Package: Compiles the application.
5. Deploy: Starts the Flask application and checks its health endpoint.
